# 기장엔지니어링 사이트 관리자

접속: https://kijeng.co.kr/admin/

## 연결

GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens에서 소유자를 lee1431, 저장소를 kj로 제한하고 Repository permissions의 Contents에 Read and write 권한을 설정합니다. 관리자 화면에 해당 토큰을 입력합니다. 토큰은 탭 메모리에서만 사용하고 브라우저 저장소나 저장소 파일에 기록하지 않습니다. 새로고침 후 다시 연결합니다. 토큰을 다른 사람에게 공유하지 마세요.

## 화면 직접 편집

1. 페이지 문구 · 이미지에서 페이지를 고릅니다.
2. 실제 사이트와 동일한 HTML/CSS와 공개 자료를 보여주는 미리보기에서 수정할 부분을 클릭합니다.
3. 오른쪽에서 문구, 이미지, 링크를 수정합니다. 이미지 파일을 직접 올릴 수 있습니다.
4. PC/모바일 화면으로 확인합니다. 상위 영역 선택으로 배경과 영역 배치를 수정합니다.
5. 변경사항 게시에서 변경 파일을 확인하고 저장합니다. GitHub Pages 자동 배포가 끝나면 실제 사이트에 반영됩니다.

미리보기는 관리 화면에 맞춰 축소됩니다. 링크 클릭은 편집 대상을 선택하며 페이지 이동은 상단 페이지 선택기를 사용합니다. 공지와 실적의 일부 페이지에 표시되지 않은 자료는 자료 관리에서 검색해서 편집합니다.

## 관리 범위

- 회사정보 · 메뉴: 회사명, 주소, 전체 페이지 메뉴 적용
- 페이지 편집: 화면의 문구, 이미지, 배경, 링크, 영역 순서·복제·삭제
- 입력폼 · 전체 HTML: 모든 문구와 SEO 메타정보, HTML 구조
- 공지 · 실적 · 상세자료: 게시물 안에서 직접 이미지·문서 파일 다중 선택 및 첨부(최대 5MB/개), 기존 파일 URL 등록, 첨부 삭제, 자료 추가·수정·삭제, 공개/비공개, 공지 고정, 분류·발주기관·연도, 회사개요·메인 문구와 미디어 영역
- 이미지 · 파일: 이미지 및 PDF 업로드, 기존 이미지 주소 확인 (파일당 5MB)
- 디자인 · 소스: 대표 색상, CSS 및 전체 페이지 소스
- 변경 이력: 최근 커밋의 파일을 초안으로 불러와 복원
- 관리 현황: 초안 JSON 백업·복원

게시물 작성 화면에서 파일을 첨부하면 초안으로만 저장됩니다. **변경사항 게시**를 눌러 GitHub에 게시하면 공개 공지사항 및 실적 화면에 파일 다운로드 링크가 나타납니다. PDF/HWP/HWPX/DOC/DOCX/XLS/XLSX/PPT/PPTX/TXT를 지원하며 실행 파일과 HTML/SVG는 허용하지 않습니다.

## 데이터 및 저장

기존 공개 API에서 가져온 about 1건, business 9건, portfolio 1,087건, notice 1건을 `data/content.json`에 보존했습니다. 이 파일이 우선 데이터 소스이며, 기존 API는 해당 파일을 가져올 수 없을 때만 사용합니다. 따라서 앞으로는 이 관리자에서 관리해야 하며 기존 API 관리자 수정은 동기화되지 않습니다. 기존 이미지 URL은 유지합니다.

저장은 blob → tree → commit → main ref의 한 번의 갱신으로 처리합니다. 저장 전 main의 변경 여부를 확인하고 force push를 사용하지 않습니다. 충돌하면 초안을 백업하고 재연결한 다음 최신 파일에 변경사항을 다시 적용하세요. 자동 병합은 하지 않습니다.

첫 배포 후 인증된 브라우저에서 게시 검증은 실제 관리자의 토큰으로 진행해야 합니다. 설치된 연결의 인증정보를 방문자 화면에 심지 않았습니다. 화면 둘러보기에서는 변경을 시험할 수 있지만 게시할 수 없습니다.
